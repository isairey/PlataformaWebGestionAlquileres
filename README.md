# 🌌 Acerca del proyecto

**House Rental Management System** es una plataforma web desarrollada con React.js orientada a la administración de propiedades y alquileres inmobiliarios mediante una experiencia moderna, rápida e intuitiva.

La plataforma permite gestionar viviendas, clientes, pagos y contratos desde una interfaz responsive basada en componentes reutilizables.

El sistema fue diseñado para:

- 🏠 Gestionar propiedades
- 👥 Administrar clientes
- 📅 Gestionar alquileres
- 💳 Supervisar pagos
- 📊 Visualizar estadísticas
- 🔐 Gestionar accesos
- 📋 Organizar contratos
- 🌐 Automatizar operaciones

# 🚀 Configuración del proyecto

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/House-Rental-Management-System.git
```

---

## 2️⃣ Instalar dependencias

### Con NPM

```bash
npm install
```

### Con Yarn

```bash
yarn
```

---

## 3️⃣ Ejecutar servidor de desarrollo

### Con NPM

```bash
npm start
```

### Con Yarn

```bash
yarn start
```

---

## 4️⃣ Abrir aplicación

```bash
localhost:[PORT]
```

El puerto se define en:

```bash
.env
```
